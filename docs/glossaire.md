# Glossaire

| Terme | Traduction / usage |
|---|---|
| Ghoul | Goule |
| Investigator | Inspecteur du CCG |
| Quinx | Quinx |
| Kagune / Quinque / Kakuhou / Kakuja | Termes conservés |
| Ukaku / Koukaku / Rinkaku / Bikaku | Types conservés |
| Half-Kakuja | Demi-kakuja |
| Full Kakuja | Kakuja complet |
| Edge | Atout |
| Gimmick | Capacité spéciale |
| Meal Score | Réserve alimentaire |
| RC Level / RCL | Niveau RC |
| RC Bonds | Liaisons RC |
| ACC | Précision (PRÉ) |
| CRL | Contrôle (CTR), distinct du niveau RC |
| END | Endurance (END) |
| PER | Perception (PER) |
| SPD | Vitesse (VIT) |
| STR | Force (FOR) |

Les formules conservent les abréviations anglaises utilisées par le système. La ressource Vitalité est écrite en toutes lettres pour la distinguer de la vitesse.
